# medpaperhub 视觉取舍说明

> **日期：** 2026-07-16
> **状态：** 实施验收依据
> **设计系统：** `design-system/paper-research-hub/MASTER.md`

## 1. 目标与结果

medpaperhub 不是论文营销站，也不是通用数据大屏。它面向医学与生物学教授、课题组负责人和科研人员，持续支持四类任务：

1. 找到最新和相关论文；
2. 比较论文、Topic 与 Method 的变化；
3. 判断研究机会并核查证据；
4. 追溯精选、趋势和推荐结论的来源与公式。

因此视觉系统选择“高可发现的学术情报工作台”而不是“学术杂志封面”或“科技品牌落地页”。
最终基线是单一亮色、数据优先、低装饰、高密度但可扫描的系统。所有页面共享
restrained navy / teal / coral + warm neutral，不允许逐页换主题。

## 2. 为什么推翻自动生成结果

初始生成文件存在结构和模式漂移：

- `MASTER` 将产品误判为 Grant / Funding Portal 与 FAQ Landing；
- 首页被写成竞品对比和 winner CTA；
- 论文页引入章节渐变、横向旅程和黑色进度条；
- 趋势页引入独立暗色模式和预测动画；
- 研究机会页被写成客服搜索与 FAQ；
- 页面分别使用绿色、黑色、章节色和状态色，无法形成统一品牌；
- motion 建议包含逐线绘制、脉冲、排名跳动和 gauge，干扰证据阅读。

本次收口不在这些建议上做局部修补，而是以产品设计文档和数据契约为事实源，重建
MASTER，再把页面文件降为纯信息架构和少量必要布局 override。

## 3. 核心视觉决策

### 3.1 单一亮色主题

页面背景使用 warm paper，卡片使用白色，结构和主操作使用 navy。该组合降低纯白数据
大屏的冷硬感，同时保留足够对比度和长时间阅读舒适度。

本版不提供单页暗色模式。趋势页尤其不得因为“数据页面”自行变暗。未来暗色主题只能
作为全局 semantic token 映射加入，并重新审计全部组件、图表、状态和焦点。

### 3.2 Navy、Teal、Coral 的固定职责

- **Navy：** 品牌、标题、主导航、主操作和稳定结构。
- **Teal：** 链接、信息发现、正向状态和主数据系列。
- **Coral：** 错误、明确风险和“当前不建议做”，不承担普通 CTA。
- **Ochre：** “谨慎做”与覆盖不足，避免把谨慎误读为错误。
- **Warm neutral：** 页面、卡片层级、分隔、缺失和证据不足。

颜色不是页面装饰。状态同时使用文字、形状、边界和数值，不让颜色单独承担含义。

### 3.3 中英文统一无衬线字体

密集门户需要稳定字面、清楚数字和良好中文 fallback。系统使用 Inter +
Noto Sans SC / Source Han Sans SC / 系统中文字体栈，标题与正文不分裂成两套品牌字体。

选择不使用 Crimson Pro 等英文衬线标题，原因是：

- 中文需要另一套字体，容易形成中英文气质断裂；
- 表格、筛选器和卡片中衬线标题会降低快速扫描效率；
- 论文内容的“学术感”应来自来源、结构和证据，不靠仿期刊排版。

标识符和窄列数字使用等宽 fallback，所有指标使用 tabular figures。

### 3.4 边框优先、阴影克制

默认卡片使用边框而非悬浮阴影。阴影只用于真实浮层和 sticky 分层。这样可以在高密度
页面中减少“每张卡都在抢注意力”的问题，也避免模仿目录站常见的营销卡片墙。

圆角控制在 `4–12px` 为主，pill 只用于短状态和标签。hover 不位移、不缩放，
避免列表扫描时产生抖动。

### 3.5 搜索和证据是两个视觉锚点

首页首屏不使用大幅营销 hero 或图片叠字。全局搜索、数据更新时间和覆盖范围直接构成
任务入口。进入趋势与机会后，Evidence Bar、数据表、公式版本和来源面板成为第二锚点，
确保用户能从结论回到证据。

## 4. 与 AgentSkillsHub 的关系

本次在 2026-07-16 对 AgentSkillsHub 类目录产品做了结构观察。参考的是“发现效率”，
不是品牌表达。

### 4.1 借鉴的发现机制

- 首屏搜索和明确的目录入口；
- 场景、类别和专题的多路径发现；
- 热门、最新、排行榜等明确集合；
- 每个条目的紧凑元数据、评分/状态和更新时间；
- 从总览到详情的可分享 URL；
- 用数量、刷新时间和方法说明建立数据边界。

这些机制被转换为论文语境：

- “技能目录”转换为论文、Topic、Method、Dataset、Benchmark、Venue；
- “评分”转换为可解释趋势指标、精选规则和机会证据；
- “安全等级”转换为论文状态、来源 provenance、许可和证据充分性；
- “场景页”转换为 Topic/Method/Venue 专题和保存筛选视图。

### 4.2 明确不复制的部分

- 不复制品牌色、闪电/霓虹语汇、黑色科技模式或视觉标识；
- 不复制安全分级字母、安装 CTA、商业审计 CTA 或安全营销叙事；
- 不复制巨大目录数字、夸张增长口号和“热门即优质”的暗示；
- 不复制 emoji 分类图标、密集装饰 badge 和多套彩色卡片；
- 不复制首页超长营销段落、商业方案和赞助位；
- 不复制卡片 hover 位移、持续脉冲和排行榜跳动动画。

medpaperhub 的差异化来自“来源可追溯、公式可解释、未知不当零、证据不足不下结论”，
而不是把 AgentSkillsHub 的品牌外观替换成论文文案。

## 5. 信息密度策略

### 5.1 保持高密度

- 论文卡按固定顺序展示身份、摘要、研究对象、来源证据和当前指标；
- 排行表对齐数值，窗口、样本和更新时间始终可见；
- 筛选保留 URL 状态，当前条件通过 chips 汇总；
- 桌面使用 discovery rail，移动端用 drawer，不删除筛选能力；
- 详情和方法说明使用渐进披露，不在首屏展开全部来源字段。

### 5.2 保持可扫描

- 一屏最多一个主问题和一个主操作；
- 卡片变体限制为少数稳定类型；
- 同一层级不用多色区分；
- 长标题允许换行，正文不小于 `16px`；
- 元数据不小于 `12px`，辅助正文保持 AA；
- 数字、时间、状态和来源位置固定，减少视线寻找。

## 6. 数据可视化取舍

### 6.1 趋势线

折线图用于连续时间变化，默认不超过四条主要系列。系列同时使用固定色、线型和文字图例。
没有边界快照时不计算变化，没有基线时不显示 `0%`。预测与历史实测必须分线型，
不得用平滑曲线制造不存在的中间值。

### 6.2 排行与比较

少量类别可用横向条形图，超过 15 项优先 Ranking Table。榜单显示值、变化、窗口、
覆盖率和更新时间，排名变化不用颜色单独编码。

### 6.3 Evidence Bar

Evidence Bar 统一展示增长、竞争密度、数据可得性、可复现性和覆盖率。每条同时显示
数值、阈值、含义和缺失状态。缺失使用明确文字和空心样式，不用零长度条伪装。

### 6.4 Opportunity Matrix

矩阵横轴为竞争密度，纵轴为增长信号。状态通过形状、文字和 semantic status 共同表达。
Data Availability、Reproducibility、confidence、coverage、limitations 和 evidence papers
进入相邻证据面板。矩阵只用于发现，不直接代替机会公式。

移动端默认使用状态分组列表，因为二维散点在 `375px` 下难以同时满足可读、触控和精确值
核查。矩阵保留为可选概览，不用缩小字体强行塞入。

### 6.5 图表替代

每张图必须提供：

- 一句文本结论；
- 时间窗口、粒度、单位和覆盖率；
- 生成时间与公式入口；
- 固定可见的“查看数据表”；
- 完整时间点、系列、单位和缺失值；
- screen-reader summary。

不采用 3D、仪表盘、饼图、环图、面积渐变、脉冲、随机色和仅 hover 可读的关键值。

## 7. 响应式取舍

### `375px`

- 任务顺序优先：搜索、筛选摘要、结果、证据；
- 论文和排行转为卡片；
- 筛选和来源进入 drawer；
- 图表减少默认系列，不删除数据表；
- 机会列表优先于矩阵。

### `768px`

- 使用 8 列网格；
- 核心表格列可见，低优先字段进入行详情；
- 首页允许 `5 + 3` 的主次组合，但趋势图仍保持整行。

### `1024px`

- 启用 discovery rail；
- 主内容使用 12 列；
- 主要筛选和完整榜单可见；
- 证据默认位于主内容下方，不强制第三栏。

### `1440px`

- 最大 shell 宽度 `1360px`；
- 持续对照任务可启用 `300px` contextual aside；
- 首页最多三列，趋势图最多两列；
- 长段文本仍限制行宽。

这些布局不是四套设计，而是同一信息优先级在不同宽度下的重排。

## 8. Accessibility 取舍

- 目标为 WCAG AA；普通文字 `4.5:1`，关键非文本 UI `3:1`。
- 手工核算的核心组合写入 MASTER，页面不得通过透明度削弱。
- 全部控件具备可见 `focus-visible`，不移除 outline。
- 路由、drawer、popover 和 modal 定义焦点进入、退出与恢复。
- 键盘可完成搜索、筛选、排序、分页和证据查看。
- 图表不是键盘或屏幕阅读器的唯一入口。
- `prefers-reduced-motion` 关闭非必要动画、平滑滚动和 shimmer。
- 支持 `200%` 文字缩放、`400%` 页面缩放和约 `320 CSS px` 重排。
- 状态不用颜色单独表达；emoji 不作为图标或信息载体。

## 9. 内容和信任

设计系统把可信度建立在以下可见信息上：

- 数据来自哪里；
- 什么时候抓取或生成；
- 使用哪个窗口和公式版本；
- 当前覆盖多少；
- 哪些信号缺失；
- 推荐有什么限制；
- 全文是否公开且允许复用；
- 精选命中了哪条规则和哪个指标年份。

文案避免“必做”“爆发”“赢家”等营销式判断。`worth_pursuing`、`proceed_with_caution`、
`not_recommended_now` 和 `insufficient_evidence` 保持四种独立状态，尤其不能把
`insufficient_evidence` 归入负向建议。
